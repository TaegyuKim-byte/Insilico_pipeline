# 기능별 워크플로우

## 기능 1. 데이터셋 등록 및 업로드

### 목적

사용자가 `.h5ad` 파일을 업로드하고, 서버가 서비스에서 사용할 수 있는 데이터셋인지 검증한 후 등록한다.

### 처리 흐름

1. **업로드 요청 접수 (Client → Dataset Management)**
    - 사용자가 `.h5ad` 파일을 업로드한다.
    - 서버는 업로드 요청을 수신하고 임시 저장소에 파일을 저장한다.
2. **데이터셋 검증 (Dataset Management)**
    - 파일 형식 및 크기를 확인한다.
    - AnnData 객체를 정상적으로 불러올 수 있는지 확인한다.
    - 기본 데이터 구조(`X`, `obs`, `var`)를 검증한다.
    - UMAP 좌표와 Neighbor Graph가 존재하는지 확인한다.
    - 기존 Leiden 결과 존재 여부를 확인한다.
3. **데이터셋 등록**
    - 모든 검증을 통과하면 원본 `.h5ad` 파일을 저장소에 저장한다.
    - 데이터셋 식별자를 생성한다.
    - 메타데이터를 등록한다.
4. **등록 결과 반환**
    - 등록이 완료되면 데이터셋 정보와 등록 결과를 클라이언트에 반환한다.
    - 검증 또는 저장에 실패하면 데이터셋을 등록하지 않고 오류를 반환한다.

## 기능 2. Leiden Clustering 분석

### 목적

등록된 데이터셋에 대해 Leiden Clustering을 수행하여 새로운 클러스터 라벨을 생성한다.

### 처리 흐름

1. **분석 요청 (Client → Analysis)**
    - 사용자가 분석 파라미터와 함께 분석을 요청한다.
2. **분석 요청 검증**
    - 데이터셋 존재 여부를 확인한다.
    - 분석 파라미터의 형식과 범위를 검증한다.
    - Leiden 분석에 필요한 Neighbor Graph가 존재하는지 확인한다.
3. **클러스터링 실행**
    - 저장된 원본 `.h5ad` 파일을 불러온다.
    - 기존 Neighbor Graph를 이용하여 Leiden Clustering을 수행한다.
    - MVP에서는 전처리, Neighbor Graph 계산, UMAP 계산은 수행하지 않는다.
4. **결과 검증**
    - 모든 세포에 클러스터 라벨이 생성되었는지 확인한다.
    - 라벨 개수와 세포 수가 일치하는지 검증한다.
5. **분석 결과 반환**
    - 생성된 클러스터 수와 라벨 정보를 클라이언트에 반환한다.
    - 분석 중 오류가 발생하면 실패 응답을 반환한다.

## 기능 3. UMAP 시각화

### 목적

등록된 데이터셋의 UMAP 좌표와 클러스터 정보를 이용하여 시각화 데이터를 제공한다.

### 처리 흐름

1. **시각화 요청 (Client → Visualization)**
    - 사용자가 특정 데이터셋의 UMAP 시각화를 요청한다.
2. **시각화 가능 여부 검증**
    - 데이터셋 존재 여부를 확인한다.
    - UMAP 좌표가 존재하는지 확인한다.
    - 클러스터 라벨이 필요한 경우 해당 결과가 존재하는지 확인한다.
3. **시각화 데이터 생성**
    - UMAP 좌표를 불러온다.
    - 클러스터 라벨이 존재하면 좌표와 결합한다.
    - 클라이언트가 바로 렌더링할 수 있는 형태의 데이터를 생성한다.
4. **시각화 데이터 반환**
    - 생성된 UMAP 데이터를 클라이언트에 반환한다.
    - 데이터가 존재하지 않거나 조건을 만족하지 못하면 실패 응답을 반환한다.

---

## 기존 클러스터 결과 시각화

기존 Leiden 결과가 포함된 데이터셋은 별도의 분석 없이 바로 시각화할 수 있다.

```
데이터셋 선택
→ 기존 Leiden 결과 조회
→ UMAP 좌표 조회
→ 시각화 데이터 생성
→ 클라이언트 렌더링
```

---

## 새 분석 결과 시각화

새로운 Leiden 분석을 수행한 경우 생성된 클러스터 라벨을 이용하여 UMAP을 다시 표시한다.

```
Leiden 분석 실행
→ 클러스터 라벨 생성
→ UMAP 좌표와 결합
→ 시각화 데이터 생성
→ 클라이언트 그래프 갱신
```
